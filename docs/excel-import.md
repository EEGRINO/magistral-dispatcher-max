# Импорт жителей из Excel

Как загрузить список жителей УК в базу одной командой: какой должна быть
таблица, как её сохранить, как закинуть на сервер и что делать с ошибками.

Готовые файлы — открываются в Excel сразу по-русски и по столбцам:

- [`templates/жители-шаблон.csv`](templates/жители-шаблон.csv) — пустой шаблон, только заголовки;
- [`templates/жители-пример.csv`](templates/жители-пример.csv) — три жителя на тестовых домах
  (дома из тестовых данных, `npm run seed`) — удобно попробовать импорт на демо-базе.

## Что загружается, а что нет

| Загружается | Не загружается |
|---|---|
| житель: телефон, ФИО | **дома** — их заводят заранее: `uk houses add` или pgAdmin ([RUN.md](RUN.md#шаг-1-завести-дома)) |
| его основная квартира: дом, подъезд, этаж, квартира, договор | **вторая и следующие квартиры** жителя — в pgAdmin, таблица `resident_premises` |
| | заявки, статусы, чаты домов |

Одна строка файла = один житель = одна квартира. Телефон в файле не должен
повторяться.

## Как должна выглядеть таблица

**Первая строка — заголовки, дальше по жителю в строке.** Порядок столбцов
любой, лишние столбцы (например, «примечание») просто пропускаются.

| телефон | адрес | ФИО | подъезд | этаж | квартира | договор |
|---|---|---|---|---|---|---|
| +7 900 000-00-11 | г. Заречный, ул. Полевая, д. 5 | Иванов Иван Иванович | 1 | 3 | 12 | Д-011 |
| 89000000012 | Полевая 7 | Petrov Petr | 2 | | 15А | |
| 9000000013 | ул. Солнечная, 12 | Сидорова Анна Сергеевна | | | | |

### Столбцы

| Заголовок (подходит любой вариант) | Обязательно | Что писать | Ограничения |
|---|---|---|---|
| **телефон** / phone | **да** | номер, по которому житель войдёт в бота: `+7 900 000-00-11`, `89000000011`, `9000000011` — скобки, пробелы и дефисы можно | 10 цифр после `+7` или `8`; в файле без повторов |
| **адрес** / address | **да** | адрес дома, как угодно: `г. Заречный, ул. Полевая, д. 5`, `Полевая 5`, `ул Полевая д.5` | дом должен быть уже заведён (см. ниже) |
| ФИО / Ф.И.О / имя / full_name | нет | `Иванов Иван Иванович` или `Ivanov Ivan` | до 200 символов |
| подъезд / entrance | нет | число | 1–100 |
| этаж / floor | нет | число; цоколь и подвал — `0` или минус | −5…200 |
| квартира / кв / apartment | нет | `12`, `12А`, `12/1` | до 16 символов |
| договор / № договора / номер договора / contract | нет | номер лицевого счёта или договора | до 64 символов; житель его нигде не вводит |

Регистр заголовков и точка на конце не важны: «Телефон», «ТЕЛЕФОН», «кв.» — всё подойдёт.

### Как сравнивается адрес

Импорт ищет дом по **улице и номеру**. Город, «ул.», «д.», «дом», запятые и
регистр отбрасываются, `ё` = `е`; корпус и литера приклеиваются к номеру
(`5 корп 2` → `5к2`, `12 А` → `12а`). Поэтому `г. Заречный, ул. Полевая, д. 5`
и `Полевая 5` — один и тот же дом.

Какие дома заведены — `uk houses list` или в pgAdmin `SELECT адрес FROM дома;`.

## Подводные камни Excel

- ⚠️ **Телефоны.** Excel превращает длинное число `89000000011` в `8,9E+10`,
  и в файл уходит испорченный номер. Перед вводом выделите столбец «телефон» →
  правой кнопкой → **Формат ячеек → Текстовый**. Или пишите номер с `+7` и
  пробелами — такой Excel не трогает.
- Один лист. Сохраняется только открытый лист.
- Без объединённых ячеек и без пустых строк сверху: заголовки — строго в первой строке.
- Пустая ячейка — «не указано» (при повторной загрузке — «не менять», см. ниже).
- Этаж и подъезд — числа, без слов: `3`, а не `3 этаж`.

## Сохранить как CSV

Импорт читает CSV, а не `.xlsx`. В Excel: **Файл → Сохранить как**, тип:

- **CSV UTF-8 (разделитель — запятая)** — лучший вариант;
- или **CSV (разделители — запятые)** — в русской Excel разделителем будет `;`.

Подходят оба: разделитель (`;`, `,` или табуляцию) и кодировку (UTF-8 или
Windows-1251) импорт определяет сам. Имя файла любое, например `жители.csv`.

## Закинуть файл на сервер

Файл должен оказаться в папке проекта — в том каталоге, который вы указали установщику (по умолчанию `/opt/max-dispatcher`). Ниже он обозначен `~/путь_до_папки_проекта`.

- **MobaXterm:** слева панель **SFTP** → перейти в `~/путь_до_папки_проекта` →
  перетащить файл мышкой.
- **WinSCP:** подключиться к серверу, перетащить файл в `~/путь_до_папки_проекта`.
- **Командой** с компьютера: `scp жители.csv root@<сервер>:~/путь_до_папки_проекта/`.

## Проверить и загрузить

На сервере, в папке проекта:

```bash
cd ~/путь_до_папки_проекта
```

**1. Проверка без записи** — `--dry-run`, в базу ничего не пишется:

```bash
docker compose exec -T api node dist/cli.js residents import - --dry-run < жители.csv
```

```
Будет: новых жителей 3, обновлённых 0, строк с ошибками 0.
Проверка (--dry-run): ничего не записано.
```

`-T` и `< жители.csv` — не опечатка: так файл передаётся команде. Если имя с
пробелами — в кавычках: `< "жители УК.csv"`.

**2. Исправить ошибки** (если есть) в Excel, сохранить CSV заново, повторить
проверку, пока ошибок не останется.

**3. Загрузить** — та же команда без `--dry-run`:

```bash
docker compose exec -T api node dist/cli.js residents import - < жители.csv
```

```
Готово: новых жителей 3, обновлённых 0, строк с ошибками 0.
```

**4. Посмотреть результат** — в pgAdmin, Query Tool:

```sql
SELECT ж.номер, ж."ФИО", ж.телефон, д.адрес, к.подъезд, к.квартира
  FROM жители ж
  JOIN квартиры к ON к.номер_жителя = ж.номер
  JOIN дома д ON д.номер = к.номер_дома
 ORDER BY ж.номер;
```

После этого жители входят в бота сами: `/start` → «Поделиться контактом».

## Повторная загрузка

Файл можно загружать сколько угодно раз — ничего не задвоится:

- житель с таким телефоном уже есть — его данные **обновляются**, новой записи нет;
- **пустая** ячейка — значение **не меняется**; **`-`** в ячейке — значение **стирается**;
- кого нет в файле — **не трогаются**. Убрать жителя — только командой
  `uk residents archive <номер>` ([RUN.md](RUN.md#шаг-3-изменить-или-убрать-жителя));
- строки с ошибками пропускаются, остальные загружаются.

## Ошибки и что с ними делать

Номер строки — как в Excel (заголовки — строка 1), если в таблице нет пустых
строк: пустые пропускаются и в счёт не идут. Телефоны в отчёт не выводятся
намеренно — это персональные данные.

| Сообщение | Что не так | Как исправить |
|---|---|---|
| `В первой строке нужны столбцы «телефон» и «адрес»` | нет одного из обязательных заголовков или они не в первой строке | переименовать заголовок, убрать строки над ним |
| `Файл пуст` | в файле ни строки | проверить, что сохранили нужный лист |
| `телефон не похож на номер из 10 цифр после +7` | цифр не 10, или Excel испортил номер (`8,9E+10`) | формат столбца «Текстовый», перепечатать номер |
| `этот телефон уже был в строке N` | один номер дважды | оставить одну строку; вторая квартира — в pgAdmin |
| `пустой адрес` | ячейка «адрес» пустая | заполнить |
| `Дом с таким адресом не заведён — сначала houses add` | дома нет в базе или адрес с опечаткой | завести дом (`uk houses add --address "…"`) или поправить адрес |
| `подъезд: нужно целое число или «-»` (или `этаж: …`) | в ячейке текст («3 этаж», «первый») | оставить только число |
| `подъезд: от 1 до 100`, `этаж: от -5 до 200` | число вне допустимого | проверить значение |
| `квартира: не длиннее 16 символов` (или договор — 64, ФИО — 200) | слишком длинный текст | сократить |
